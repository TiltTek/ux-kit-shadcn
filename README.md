# Tilttek UX kit for Shadcn

Tailwind versions, in the style of the Shadcn kit, of the Tilttek kit recipes, installed with `ux:install --kit=github.com/TiltTek/ux-kit-shadcn`.

This repository is split from the Tilttek monorepo, where it is developed; changes are made there.
